### 🐚 Mi Entorno de Terminal (Shell Productive Setup)

Me encanta optimizar mi flujo de trabajo directamente desde la línea de comandos mediante scripts personalizados y alias eficientes:

| Comando / Alias | Descripción |
| :--- | :--- |
| `ls` | Lista el contenido de directorios de manera limpia |
| `cd` | Navegación rápida entre estructuras de proyectos |
| `yarn` | Gestión ágil de paquetes y dependencias frontend |
| `gst` | Alias personalizado para revisar el estado de Git rápidamente (`git status`) |
| `clear` | Limpieza instantánea del buffer de la terminal |

> 💡 **Tip de productividad:** Si quieres descubrir cuáles son tus herramientas más utilizadas en tu entorno Unix, puedes añadir mi alias favorito a tu archivo de configuración (`.bashrc` o `.zshrc`):
> ```bash
> alias mostused='history | awk '\''{print $2}'\'' | sort | uniq -c | sort -nr | head -n 10'
> ```
